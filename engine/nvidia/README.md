# NVIDIA DLSS and DLAA for captured video

`NgxVideo` creates an NVIDIA NGX feature on the active effects device for the selected mode and checks the result of each evaluation. At native resolution it requests DLAA. In Auto it requests Quality below 2× enlargement per dimension, Performance from 2×, and Ultra Performance from 3×. Manual Quality, Balanced, Performance and Ultra Performance use the selected NGX quality flag at the actual stream and output dimensions. At 1×, the player retains the preference for the next enlargement. Set the model preference to Driver default, K (DLSS 4), M (DLSS 4.5, optimized for Performance) or L (DLSS 4.5, optimized for Ultra Performance). P5Cast supplies the selected hint when creating the NGX feature. NVIDIA’s driver can override it. The reported preference identifies the request sent by the player. [NVIDIA’s model descriptions](https://www.nvidia.com/en-us/geforce/news/dlss-4-5-geforce-game-ready-driver/) The renderer supplies color, pixel-space motion toward the previous frame, normalized depth, a history-reset signal and the output texture. For capture sources, the host estimates motion from video and uses flat depth. Real game-engine vectors, per-object depth and the original camera jitter are unavailable.

On Direct3D 12 the renderer submits shader work through D3D11On12 and calls the native D3D12 NGX and RTX Video SDKs on the same command queue. The bridge unwraps each input and output as an ID3D12Resource, transitions it for compute access, and returns it to the translated shaders with a completion fence. To verify both native GPU paths on a compatible RTX card, run `.\engine\nvidia\Test-Ngx.ps1 -Backend d3d12` and `.\engine\rtxvideo\Build.ps1 -Verify -VerifyBackend d3d12`.

DLSS 5 3D-guided neural rendering is a separate native-resolution picture mode. The optional Vulkan integration uses the official neural-rendering build dependency pinned by RTX Remix 1.6.1. The general Streamline 2.14.16 SDK omits this plugin. P5Cast processes SDR video and estimates motion from the stream. The neural-rendering device uses Vulkan on the selected GPU. Staging buffers transfer frames between the playback and neural-rendering devices, which adds latency. An on-device image test controls availability. The local RTX 4090 can validate the unsupported-device behavior. Testing image quality and latency on RTX 50-series hardware is pending. [RTX Remix 1.6.1 dependency manifest](https://github.com/NVIDIAGameWorks/dxvk-remix/blob/0a6cd5b1ee814ec390c358e0c9c32ece8895ddc0/packman-external.xml) · [NVIDIA reference implementation](https://github.com/NVIDIAGameWorks/dxvk-remix/blob/0a6cd5b1ee814ec390c358e0c9c32ece8895ddc0/src/dxvk/rtx_render/rtx_ngx_wrapper.cpp)

The renderer checks stationary edges before assigning a block motion vector to text. A source-resolution mask identifies narrow, nearly neutral strokes. After the NGX evaluation, a GPU pass uses the source RGB around those strokes to limit changes in local contrast. For moving text and highlights, the renderer compares bright, nearly neutral pixels against the current source frame to preserve their luminance. It repeats this comparison at the final display size when the picture is fitted into a smaller viewport.

Run `.\tests\Smoke-NgxQuality.ps1 -Display '\\.\DISPLAY2'` with an HDR display to compare the final SDR and HDR10 output against Original. The fixture measures uniform patches, fractional coverage at text edges, luminance loss on moving white HUD elements, and changes in moving detail.

The Windows build downloads the official NVIDIA release runtime and build inputs at a fixed revision, checks each file against `sdk-files.json`, and validates the runtime's Authenticode publisher. The compiler helper uses an active x64 Visual Studio developer shell or fetches the pinned Microsoft toolchain into the current user's build cache. Packaged users run the existing binaries.

From the repository root, after building the player and its SharpDX dependencies, run:

```powershell
.\engine\nvidia\Build.ps1 -OutDir .\engine\bin -Verify
```

The motion test runs 14 genuine NGX evaluations per mode. Separate neutral-field tests check five SDR code values from black to reference white and four FP16 HDR levels from 20 to 1000 nits. GPU readback checks that a changing input changes the output. A stationary pattern is repeated for eight frames after a history reset, then compared against a native-size reference for DLAA and a bilinearly enlarged reference for DLSS. The reported differences establish that each effect changes the image. Evaluating perceived quality requires real gameplay.
