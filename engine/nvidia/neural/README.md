# DLSS 5 Neural Rendering on Windows

P5Cast uses the Vulkan NGX integration published with [RTX Remix 1.6.1](https://github.com/NVIDIAGameWorks/dxvk-remix/blob/0a6cd5b1ee814ec390c358e0c9c32ece8895ddc0/packman-external.xml). The pinned build dependency is `rtx-remix-ngx_sdk_dlnr@2`. Its Windows x64 runtime reports version 310.9.16.0. The application distributes its native bridge and the accompanying NVIDIA SDK license. The optional runtime is installed separately in the user's P5Cast provider directory.

This path uses a dedicated Vulkan device matched to the selected adapter by device UUID. NGX supplies its required instance and device extensions before device creation. The first implementation uses synchronous staged frame transfers between the DXVK renderer and the provider. A GeForce RTX 50 Series machine is needed to measure real neural rendering frame time and inspect results. The capability probe requires an evaluated image before exposing the feature.

The working image is same-resolution, gamma-encoded SDR in RGBA16F. Remote Play supplies a final composite. Motion estimates, approximate depth and a white material mask are supplied to the model. The reference implementation supplies scene data from its renderer. See [Remix resources](https://github.com/NVIDIAGameWorks/dxvk-remix/blob/0a6cd5b1ee814ec390c358e0c9c32ece8895ddc0/src/dxvk/rtx_render/rtx_resources.cpp), [neural rendering](https://github.com/NVIDIAGameWorks/dxvk-remix/blob/0a6cd5b1ee814ec390c358e0c9c32ece8895ddc0/src/dxvk/rtx_render/rtx_ngx_wrapper.cpp#L1107-L1210) and [input tone mapping](https://github.com/NVIDIAGameWorks/dxvk-remix/blob/0a6cd5b1ee814ec390c358e0c9c32ece8895ddc0/src/dxvk/shaders/rtx/pass/tonemap/tonemapping_fast_tonemapping.comp.slang).

From a built player checkout, run `engine\nvidia\neural\Build.ps1 -Verify`. This checks three distinct FP16 images through the selected physical GPU using an independent Vulkan copy and verifies the production missing-provider/hardware gate. The unified player's normal `--capabilities --renderer vulkan` check evaluates the actual provider and validates its output when hardware and installation permit.

The provider archive contains NVIDIA’s RTX SDK license and supplement. Those cover runtime incorporation and distribution, NVIDIA attribution, GPU and cloud use, and notification before commercial release. Review the exact copy installed with the application. The [general Streamline SDK](https://github.com/NVIDIA-RTX/Streamline/releases/tag/v2.14.16) does not include the NR runtime.
